# Future Now — React frontend

React 19 + Vite 8. FastAPI обслуговує API й готову збірку з одного origin. Залежності зафіксовані в `package-lock.json`.

## Рівні застосунку

```text
src/
  app/
    AppProvider.jsx      сесія, спільний стан, дії користувача
    AppShell.jsx         оболонка, навігація, повідомлення, діалоги
  routing/
    routes.js            перелік маршрутів, групи, доступ адміністратора
    PageRouter.jsx       відкладене завантаження екранів
  hooks/
    useRemoteResource.js запити, помилки, захист від застарілих відповідей
    useDebouncedValue.js пошук після паузи у введенні
    useLocale.js         локалізація, дати, тексти помилок
    useToast.js          тимчасові повідомлення
  pages/
    Auth.jsx             вхід і реєстрація
    Catalog.jsx          пошук, фільтри, пагінація, обране
    Categories.jsx       напрями, пошук напряму, перехід до каталогу
    Account.jsx          профіль, налаштування, інформація про сервіс
    Proposals.jsx        пропозиції користувача та модерація
    Help.jsx             пошук відповідей і повідомлення про проблему
  components/
    Common.jsx           форми, кнопки, поля, native dialog / React portal
    Layout.jsx           верхнє й нижнє меню, навігація особистого кабінету
    Overlays.jsx         оголошення, анкета, скарга та перегляд пропозиції
    Icons.jsx            SVG-іконки
  api.js                 fetch, cookie, CSRF, помилки API
  context.jsx            доступ компонентів до стану та спільні функції
  i18n.js                українські й англійські тексти
  styles.css             візуальна система
  sections.css           напрями та центр допомоги
  responsive.css         сітки, сенсорні елементи, орієнтація, safe area
```

## Розділи

Маршрути: `#explore`, `#categories`, `#saved`, `#suggest`, `#proposals`, `#profile`, `#settings`, `#help`, `#about`, `#moderation`. Останній доступний адміністратору; сервер окремо перевіряє його права. Невідомий маршрут відкриває каталог. Назад/вперед у браузері працюють через hash navigation.

Екрани й діалоги завантажуються окремими JS-модулями в момент відкриття. Спільний provider зберігає сесію та вподобання між екранами. Паролі й сесійні токени не записуються в localStorage. Тексти API відображаються через JSX.

Вибір напряму змінює тип можливості та зберігає решту фільтрів. Центр допомоги має пошук у відповідях і форму повідомлення через існуючий `/api/v1/me/reports`.

## Адаптація

- До 480 px: одна колонка оголошень і форм, нижнє меню.
- 480–767 px: дві колонки оголошень, нижнє меню.
- 768–1023 px: дві колонки, верхня навігація, фільтри в діалозі.
- Від 1024 px: фільтри в боковій панелі.
- Від 1440 px: три колонки оголошень.

Для сенсорних пристроїв збільшені області нажаття й поля від 16 px. Враховані safe-area, динамічна висота viewport, горизонтальне положення й prefers-reduced-motion. Кнопка закриття оголошення залишається доступною під час прокрутки. Довгі форми прокручуються у межах екрана.

## Запуск

Із кореня сайту:

```powershell
npm ci --prefix frontend
npm run build --prefix frontend
.\START_WEBSITE.bat
```

Сайт: `http://127.0.0.1:8002`. Для розробки з уже запущеним FastAPI:

```powershell
npm run dev --prefix frontend
```

Vite: `http://127.0.0.1:5173`. Його proxy передає `/api` та зображення на `8002`. Після редагування виконайте build, щоб оновити сайт FastAPI. Збірка очищає лише `../static/react`; фотографії у `../static/images` зберігаються.
