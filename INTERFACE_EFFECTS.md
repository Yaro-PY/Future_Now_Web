# Ефекти інтерфейсу Future Now

На світлих сторінках після входу працює синій ElectronicSpider. На темній сторінці входу його немає.

- Натискання на видиму частину павука відкриває меню тільки над вільним фоном. Картки, кнопки, поля, посилання та текст мають пріоритет; Canvas не перехоплює їхні натискання.
- «Приховати на цю сесію» зберігається в sessionStorage поточної вкладки, включно з оновленням сторінки. У новій вкладці павук знову показується.
- «Помічник по сайту» шукає справжні курси в активному каталозі за запитом звичайною мовою. Враховує тему, формат, вартість, точний вік, рівень та інші умови; уточнення зберігають контекст. Картки відкривають окрему сторінку курсу, а кнопка «Показати ще» завантажує наступні результати. Також є підказки щодо розділів сайту.
- Це розмовний пошук за правилами та метаданими каталогу, без зовнішньої генеративної моделі. Якщо збігів немає, помічник повідомляє про це та пропонує явно змінити умови. Чат зберігається лише в пам’яті поточної React-сесії; повідомлення не записуються в БД і не надсилаються стороннім API. Закриття панелі не очищає розмову; кнопка нової розмови очищає її.
- POST /api/v1/assistant/message потребує сесії та CSRF-токена. Пошук не змінює збережені фільтри профілю. Кнопка перенесення у каталог доступна лише для умов, які каталог може точно відтворити.
- Є клавіатурний доступ до меню, підтримка сенсорних екранів і prefers-reduced-motion. При відкритті вікон анімація призупиняється.
- Усі діалоги й меню профілю використовують світлий ефект рідкого скла замість темного затемнення. SVG додає легку рефракцію; звичайне світле розмиття служить резервним варіантом. Саме вікно залишається чітким.

Підключення: frontend/src/app/AppShell.jsx та frontend/src/main.jsx. Компоненти: ElectronicSpider.jsx, SpiderAssistant.jsx, LiquidGlass.jsx. Рендер і попадання: frontend/src/effects/. Стилі: electronic-spider.css і liquid-glass.css.

Інтерфейс працює через React; пошук реалізовано в assistant_api.py та assistant_search.py на наявному FastAPI-бекенді. Нові залежності, змінні середовища та міграції БД не потрібні. Збірка: npm run build --prefix frontend. Vercel збирає frontend через наявний buildCommand.

## Публічні сторінки можливостей

Кожне оголошення має адресу /opportunities/{id}/{slug}. ID постійний; старі назви й адреси без slug перенаправляються на поточну адресу. Міграція БД не потрібна.

Перегляд та перехід до реєстрації доступні без входу. Обране, нагадування та скарги потребують сесії; зміни також перевіряють CSRF. Вхід повертає до оголошення. Адреса повернення обмежена локальними сторінками можливостей.

Каталог, обране, пропозиції, адмінка та помічник відкривають ці сторінки. Картки підтримують відкриття в новій вкладці. «Поділитися» використовує адресу Future Now. Завершені оголошення збережені зі статусом без кнопки реєстрації; невідомі ID повертають HTTP 404. HTML містить canonical та Open Graph, текст оголошень екранується.

## Вигляд і постійне приховування павука

Налаштування → «Вигляд і павук»: синій, лимонний, помаранчевий, червоний або зелений акцент; перемикач показу павука. Зміни застосовуються кнопкою «Зберегти» та зберігаються у спільному профілі. Старі профілі мають синій акцент і ввімкненого павука. Персональні налаштування повертає /me; PATCH /me/settings приймає appearance.accent та appearance.spider_enabled і перевіряє сесію та CSRF.

Зберігання використовує окремий ключ _appearance в наявному JSON accounts.notifications; публічний контракт сповіщень містить лише new/deadlines/expired. Зміна сповіщень, мови та профілю зберігає вигляд. Міграції й нові змінні середовища не потрібні. Постійне вимкнення діє на пристроях після завантаження профілю; увімкнення в налаштуваннях також скасовує тимчасове приховування цієї вкладки. Кнопка приховування на сесію залишається в меню павука.

## Відеозаставка входу

Файли зберігаються в static/media/auth; оригінали збережені поруч із веб-версією відео та постером. AuthMedia.jsx замінює колишній фон входу; кнопки звуку і відео розміщені біля перемикача мови. Музика увімкнена за замовчуванням. Якщо браузер блокує автоматичний старт, відтворення починається після першої взаємодії зі сторінкою. Кнопка звуку зберігає вибір у браузері. Оригінальний звук відео вимкнений. Відтворення призупиняється на прихованій вкладці та завершується після виходу зі сторінки входу. API та БД не змінюються.

Vercel build запускає prepare_public_media.py, який копіює тільки веб-відео, постер та MP3 у public/assets/media/auth для прямої видачі через CDN. Ця папка генерується з файлів для відтворення у static/media/auth та не додається вдруге до Git. Локально ті самі URL обслуговує наявний StaticFiles.
