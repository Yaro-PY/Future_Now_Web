# Файли заставки входу Future Now

- lusion.mp4 — оригінальне відео, надане користувачем.
- cash_cash_ft_tritonal_-_untouchable_extended_mix.mp3 — оригінальна музика, надана користувачем.
- lusion-background.mp4 — полегшена H.264 версія відео без звукової доріжки, 1280×960, 30 кадрів/с, faststart.
- lusion-poster.jpg — статичний кадр для завантаження, помилки або вимкненої анімації.

На сторінці входу відео повторюється, а музика вмикається автоматично або після першої взаємодії, якщо браузер обмежує автоматичне відтворення. Початкова гучність — 10 %. Кнопка звуку й повзунок зберігають вибір у браузері. Після входу або переходу зі сторінки відтворення та завантаження зупиняються. На прихованій вкладці медіа призупиняються. У режимі зменшення руху відео очікує ручного запуску. Реєстрація та 2FA використовують ту саму заставку.
